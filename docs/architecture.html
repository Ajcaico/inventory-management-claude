Data flow

How a filter change on the dashboard becomes new numbers on screen.

  1. User changes a filterFilterBar updates shared refs in useFilters (period, warehouse, category, status). They are module-level singletons, so every view sees the same state.
  2. View reloads its dataThe view calls getCurrentFilters() and passes the result to an api.* method.
  3. Client builds the requestapi.js drops any filter set to all and sends the rest as query params, e.g. /api/orders?warehouse=...&month=Q3-2025.
  4. Server filters in memoryThe route handler runs apply_filters() and filter_by_month() over the lists loaded by mock_data.py.
  5. Server validates and respondsPydantic checks list and detail responses against response_model. Dashboard summary and report routes return plain dicts.
  6. Client rendersRaw results land in refs; computed properties derive totals, chart series and table rows, and Vue re-renders.
FilterQuery paramApplies to
Time periodmonthOrders, dashboard summary. Accepts YYYY-MM or Q1-2025 to Q4-2025
WarehousewarehouseInventory, orders, summary
CategorycategoryInventory, orders, summary (case-insensitive)
Order statusstatusOrders, summary (inventory has no status)

Inventory has no date field, so the period filter does not affect it. Demand, backlog and spending routes take no filters.

Gaps found while reading the code

Worth knowing before building on this. These come from reading the source, not from running every screen.

FindingDetail
Missing endpointsapi.js calls /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders (POST, GET), but main.py defines none of them. The task list in App.vue and the purchase-order flow will fail against this backend. The server also has no write routes at all, and its CreatePurchaseOrderRequest and PurchaseOrder models are unused.
Unrouted viewBacklog.vue exists but main.js registers no route for it, so it is unreachable by URL.
Inconsistent API accessReports.vue bypasses api.js and hard-codes http://localhost:8001; api.js hard-codes it too. There is no environment-based base URL or Vite proxy.
Duplicated quarter logic/api/reports/quarterly re-implements the quarter mapping instead of reusing QUARTER_MAP. Both are fixed to 2025.
By design (demo)CORS allows all origins, there is no real authentication (the user is a hard-coded object in useAuth.js), and data resets on restart.
